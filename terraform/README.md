# RocketTail Terraform Infrastructure

Este componente contém as definições de infraestrutura como código (IaC) para deploy dos recursos na AWS.

## Setup e Execução
Inicialize o diretório do Terraform:
```bash
cd terraform
terraform init
```

Gere um plano de execução:
```bash
terraform plan
```

Execute a infraestrutura:
```bash
terraform apply
```
